# M3U8 投屏助手

一个专门给 Chrome 用的本地扩展：

- 自动监听页面里的 `m3u8` 请求
- 在弹窗里查看最近捕获到的播放地址
- 通过 DLNA 把 `m3u8` 直接推送到小米电视

## 现在的能力

1. 后台通过 `webRequest` 监听全站请求，自动抓取 `.m3u8` 链接。
2. 支持按时间查看最近捕获记录，并一键复制、删除、填入当前投屏框。
3. 支持填写小米电视的 DLNA 描述地址，自动解析 `AVTransport` 控制地址。
4. 支持直接向电视发送 `SetAVTransportURI` 和 `Play` 指令。

## 使用方式

1. 打开 `chrome://extensions/`
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录 `D:\yx\chuqie`
5. 打开目标视频页面并开始播放
6. 点击扩展图标，确认已经抓到 `m3u8` 链接
7. 在“电视设置”里填入小米电视的 DLNA 描述地址或直接填控制地址
8. 点击“投屏”

## 设备配置说明

- 推荐填“设备描述地址”，扩展会自动解析控制地址。
- 常见格式类似：`http://电视IP:端口/description.xml`
- 如果你已经知道 `AVTransport` 的 `controlURL`，也可以直接填“AVTransport 控制地址”。

## 注意事项

- 电脑和小米电视需要在同一个局域网。
- 小米电视端需要开启 DLNA / 米联 / 投屏相关能力。
- 如果 `m3u8` 依赖 `Cookie`、`Referer`、登录态或临时签名，电视端可能无法直接拉流。
- 这个版本没有做局域网自动发现，当前采用“手动填设备地址 + 自动解析服务”的方式，稳定性更高。
