# M3U8 投屏助手

一个给 Chrome 用的本地扩展：

- 自动监听页面里的 `m3u8` 请求
- 在弹窗里查看最近捕获到的播放地址
- 通过 DLNA 把 `m3u8` 直接推送到小米电视
- 扫描局域网里的可投屏设备并一键设为当前电视

## 现在的能力

1. 后台通过 `webRequest` 监听全站请求，自动抓取 `.m3u8` 链接。
2. 支持按时间查看最近捕获记录，并一键复制、删除、填入当前投屏框。
3. 支持填写小米电视的 DLNA 描述地址，自动解析 `AVTransport` 控制地址。
4. 支持扫描指定局域网网段下的常见 DLNA 描述地址，并识别可投屏设备。
5. 支持直接向电视发送 `SetAVTransportURI` 和 `Play` 指令。

## 使用方式

1. 打开 `chrome://extensions/`
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录 `D:\yx\chuqie`
5. 打开目标视频页面并开始播放
6. 点击扩展图标，确认已经抓到 `m3u8` 链接
7. 在“局域网扫描”里填写网段前缀，例如 `192.168.1`
8. 扫描到设备后，点击“设为当前设备”或“用它投屏”

## 设备配置说明

- 推荐先使用“局域网扫描”。
- 如果你已经知道设备描述地址，也可以手动填写。
- 常见格式类似：`http://电视IP:端口/description.xml`
- 如果你已经知道 `AVTransport` 的 `controlURL`，也可以直接填“AVTransport 控制地址”。

## 扫描说明

- 由于普通 Chrome 扩展没有稳定可用的原生 SSDP 广播能力，这个版本采用“扫描常见 DLNA 端口和描述地址”的方式发现设备。
- 默认最适合扫描单个 `/24` 网段，例如 `192.168.0.*`、`192.168.1.*`、`192.168.31.*`。
- 如果没扫到设备，优先检查你填写的网段前缀是否正确。

## 注意事项

- 电脑和小米电视需要在同一个局域网。
- 小米电视端需要开启 DLNA / 米联 / 投屏相关能力。
- 如果 `m3u8` 依赖 `Cookie`、`Referer`、登录态或临时签名，电视端可能无法直接拉流。
- 局域网扫描依赖常见端口探测，不保证发现所有品牌和所有固件版本的电视。
